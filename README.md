# Hello World App

A simple Hello World application built with HTML5 and JavaScript.

## How to Run

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Click the "Say Hello" button to see the greeting message appear, or watch the typing animation on load.

## Project Structure

```
.
├── index.html      # Main HTML5 markup
├── style.css       # Styling for the page
├── script.js       # JavaScript logic
└── README.md       # Project documentation
```

## Features

- Clean, responsive HTML5 layout
- Animated typing effect for the "Hello, World!" message
- Interactive button to re-trigger the greeting
- Simple, dependency-free JavaScript (no frameworks required)
